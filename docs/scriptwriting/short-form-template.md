# Short-form architecture

Applies every principle in [`core-psychology.md`](core-psychology.md). This
file only covers what's different because the format is short and loops.

## Structure

```
Compressed hook (1–2 lines)
  → single loop / payoff
  → last line wired to loop back into line 1
```

No multi-point body, no outline stage, no outro — the whole video is the
hook and its payoff.

## 1. The compressed hook

Same [4-part skeleton](core-psychology.md#4-the-4-part-hook-skeleton) as
long-form — context, common belief, contrarian take, proof + plan — but
collapsed into 1–2 sentences. Beats often double up in a single line rather
than each getting its own.

Two extra rules specific to short-form, because the margin for error here is
near zero:

- **The first line must be punchy and plot-indicative.** State directly what
  the video is about or the payoff it's building to (e.g. "these are the
  best techniques for X," "I've got a garden trick that..."). Do **not**
  open on an opaque teaser ("wait till you see this," "you won't believe
  this") — if line one doesn't immediately signal the plot, the viewer is
  gone before the common-belief/contrarian beats even land.
- **Pair the hook with a visual, not just audio.** Per the core rule, a
  concrete on-screen visual that reinforces the hook's subject (not just a
  talking mouth + captions) retains dramatically better — the viewer should
  know the topic from what's on screen before they've processed a word.

## 2. Single loop → payoff

Short-form has no room for the long-form body's multi-point, ordered
structure. There's one loop: open it in the hook, deliver the payoff, done.

**If** a short does stack 2–3 quick beats (e.g. a mini-listicle short), apply
a scaled-down version of long-form's escalation: put the 2nd-best beat
before the best beat, not the reverse. Leading with your single best beat
trains the viewer that value is about to decline, and they leave; a small
upward step keeps them through to the end. Skip this entirely for
single-payoff shorts — it only applies when there's more than one beat to
order.

## 3. Last line loops back to line 1

Short-form video replays on loop, so the last line isn't an ending — it's
written as a setup for the first line when it plays again. Write the first
and last line together, before filling in the middle, so the loop is
intentional rather than accidental. Make the last line memorable enough on
its own that someone who only heard that one line would still share it.

## Checklist before shipping a short-form script

- [ ] First line names the plot directly — no opaque teaser
- [ ] Hook has a paired visual, not audio-only
- [ ] All 4 hook beats present, even if compressed into 1–2 lines
- [ ] Beat-to-beat connectors are but/therefore, not and-then ([the Dance](core-psychology.md#the-dance--butthereforenever-and-then))
- [ ] Sentence lengths vary (no flat right edge when laid out one-per-line)
- [ ] Last line was written together with the first line, and loops into it
- [ ] If multi-beat: 2nd-best beat lands before best beat
