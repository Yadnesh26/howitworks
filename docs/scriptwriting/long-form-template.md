# Long-form architecture

Applies every principle in [`core-psychology.md`](core-psychology.md). This
file only covers what's different for a long-form script: room for a full
outline stage, an uncompressed intro, and a multi-point body.

## Structure

```
Packaging (idea / title / story lens — see core)
  → Outline (bulleted, uniqueness gut-check)
  → Intro (full 4-part hook)
  → Body (multi-point, ordered, each point run through the value loop)
  → Outro
```

Write in this order — outline before intro, intro before body — even though
that's not viewing order. The reasoning: the hook is a known, learnable
formula (step 3), so it's low-risk to leave for after the outline; the
outline is where you find out whether the video has anything unique to say
at all (step 2), which is the actual risk in the video, so resolve it first.

## 1. Outline first, gut-check for uniqueness

Before writing prose, write a quick bulleted outline of your body points.
Then zoom out and ask honestly: is this unique, or is it a summary of things
the viewer already knows? Per the master principle, if your points are just
existing base knowledge restated, you cannot beat the viewer's expectations
— they already know it, so there's no gap for reality to win.

If the outline isn't unique, don't proceed to writing the script — go back
and research more, or find a different angle (see
[story lens](core-psychology.md#3-packaging-idea-title-story-lens)), until
the outline passes this check. This is the "measure twice, cut once" stage:
cheap to redo here, expensive to redo after the script is written.

For each bullet, layer on **what** it is, **why** it matters, and **how** it
fits the overall story — this becomes the seed for the value loop each point
gets expanded into later.

## 2. Full 4-part intro

Same [4-part skeleton](core-psychology.md#4-the-4-part-hook-skeleton) as
short-form, but uncompressed — each beat (context, common belief,
contrarian take, proof + plan) gets its own line or lines rather than being
folded together. There's room here to actually build the contrast before
resolving it, unlike short-form's near-instant version.

## 3. Body: ordered points, each through the value loop

**Ordering — 2nd-best point first, not your best point first.** Counterintuitive,
but: showing one great point registers as "cool." Showing a great point
followed by an even better one creates a subconscious pattern of *rising*
value, and the viewer stays to see if it keeps climbing. Lead with your best
point and the pattern reads as *declining* value from there, and viewers
leave. So: 2nd-best → best → 3rd-best → ... — climbing, not descending.

This ordering matters most for the very first body point specifically: it's
the first thing the viewer hears after the intro's promises, and if it's
underwhelming or already-known, the video loses them right there, before
the better points ever arrive.

**Per point — the value loop**, three parts, in this order:
1. **Context** — what it is, stated as simply as possible.
2. **Application** — how to do it, with concrete examples.
3. **Framing** — why it matters, how it connects back to the overall story.

This context → application → framing progression mirrors how the point
should land: surface fact first, then the reader can act on it, then they're
reoriented to why it was worth hearing.

**Connect points with but/therefore** ([the Dance](core-psychology.md#the-dance--butthereforenever-and-then)),
never and-then — this is what stops a multi-point body from reading as a
flat list.

## 4. Outro

Close out the video. Since long-form doesn't loop, the outro doesn't need
the short-form last-line mechanic — it just needs to land the video's
overall payoff and (optionally) the next action for the viewer.

## Checklist before writing the script itself

- [ ] Idea, title, and story lens locked (see core) before outline starts
- [ ] Outline passes the uniqueness gut-check — not a restatement of common
      knowledge
- [ ] Each outline bullet has a what/why/how before expansion
- [ ] Intro hits all 4 beats, each given real room (not compressed)
- [ ] Body points ordered 2nd-best → best → 3rd-best → ...
- [ ] Every body point runs through context → application → framing
- [ ] Point-to-point transitions are but/therefore, not and-then
- [ ] Sentence lengths vary throughout (no flat right edge one-per-line)
